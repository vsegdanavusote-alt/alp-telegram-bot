# Альп-Пром Telegram Бот

Telegram бот для компании «Альп-Пром» (промышленный альпинизм, Харьков)

## Функции
- 📝 Приём заявок
- ❓ FAQ
- 📞 Контакты
- ℹ️ О компании

## Деплой на Render
1. Зайди на render.com
2. Подключи GitHub
3. New → Web Service
4. Выбери репозиторий alp-telegram-bot
5. Добавь переменные:
   - TELEGRAM_TOKEN
   - ADMIN_ID
6. Deploy!
